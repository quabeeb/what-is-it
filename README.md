# ✈️ Project Skywriter

An interactive flight radar challenge web app.

---

## 💻 Local Testing / How to Run

No installations, build steps, or package dependencies required.

### Option 1: Direct in Browser
Double-click `index.html` (or open it in Chrome, Edge, Safari, or Firefox).

### Option 2: Local HTTP Server
Run any local static web server from the project root:

```bash
# Python 3
python -m http.server 8080
```

Then open `http://localhost:8080` in your browser.

---

## 🚀 GitHub Pages Deployment

1. Push your code to GitHub:
   ```bash
   git push origin main
   ```
2. In your GitHub repository, go to **Settings** &rarr; **Pages**.
3. Under **Build and deployment**:
   - **Source**: Select `Deploy from a branch`
   - **Branch**: Select `main` and folder `/(root)`
4. Click **Save**. Within 1 minute, the site will be live at:
   ```
   https://<username>.github.io/<repository-name>/
   ```
